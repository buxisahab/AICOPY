WHY THIS WORKS:
───────────────────────────────────────────────────────────────

The variables isCurrentlyRunning and canResume are already defined
at the top of the DownloadItem composable (lines 64-74):

    val isCurrentlyRunning = remember(mission.running, mission.isPaused, mission.finished) {
        mission.running && !mission.isPaused && !mission.finished
    }
    
    val canResume = remember(mission.finished, mission.running, mission.isPaused) {
        !mission.finished && !mission.running && mission.isPaused
    }

These use Compose's remember() with dependencies, so they automatically
recalculate when mission.running, mission.isPaused, or mission.finished
changes. This ensures the button icon updates INSTANTLY when the event
bus fires and the mission state changes.
